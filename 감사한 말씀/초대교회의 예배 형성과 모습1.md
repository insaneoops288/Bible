# 초대교회의 예배 형성과 모습

초대교회의 예배는 오늘날 기독교 예배의 원형이자 모태입니다. 유대교 전통의 연속성 속에서 예수 그리스도의 십자가와 부활이라는 결정적 사건을 중심으로 독창적인 예배 양식을 확립해 나갔습니다.

---

## 1. 초대교회 예배의 배경과 기원

초대교회 예배는 크게 두 가지 역사적·신앙적 뿌리를 가지고 있습니다.

1. **유대교 회당(Synagogue) 예배 전통**
   - 구약성경 낭독, 시편 찬송, 기도, 랍비의 설교(강론)로 이루어진 회당의 ‘말씀 중심’ 구조가 기독교 예배의 전반부(말씀의 예전)로 흡수되었습니다.
2. **최후의 만찬과 유월절 전통**
   - 예수께서 잡히시던 밤 제자들과 나누신 만찬에 기초하여, 떡을 떼고 포도주를 나누는 ‘성찬(Eucharist)’이 예배의 후반부(식탁의 예전)로 자리 잡았습니다.
3. **‘안식일’에서 ‘주의 날(주일)’로의 전환**
   - 초대 그리스도인들은 초기에는 안식일(토요일) 회당 모임에도 참석했으나, 예수께서 부활하신 "안식 후 첫날"(일요일) 이른 아침이나 저녁에 모여 떡을 떼기 시작했습니다. 이 날은 '주의 날(Lord's Day)'로 불리며 기독교의 공적 예배일이 되었습니다.

---

## 2. 시대별 형성 과정

### 1) 사도 시대 (1세기: 신약성경 속 예배)
- **가정 교회(House Church):** 신자들은 대형 건물이 아닌 성도들의 집(가정)에 모였습니다(롬 16:5, 고전 16:19).
- **말씀과 떡을 뗌:** 사도행전 2장 42절에 기록된 바와 같이, "사도들의 가르침을 받아 서로 교제하고 떡을 떼며 오로지 기도하기를 힘쓰는" 형태였습니다.
- **애찬(Agape Feast)과 성만찬의 결합:** 초기에는 실제 저녁 식사(애찬)를 나누는 자리에서 자연스럽게 성만찬으로 이어졌습니다. 그러나 고린도전서 11장에서 지적되듯 식사 질서 문제가 발생하면서 점차 애찬과 성찬이 분리되었습니다.

### 2) 교부 시대 (2~3세기: 예전의 정형화)
박해와 이단의 위협 속에서 예배의 질서와 교리적 일관성이 강조되었습니다.

- **디다케(Didache, 1세기 말~2세기 초):** 주일 성수, 세례, 기도(주기도문 하루 세 번 암송), 성찬 기도문 등에 관한 구체적 지침이 기록되었습니다.
- **순교자 저스틴(Justin Martyr, 주후 150년경)의 『제1변증서』:**
  - 기독교인이 황제나 로마 사회로부터 오해(식인, 근친상간 등)를 받자, 황제 안토니누스 피우스에게 보낸 편지에서 **당시 주일 예배의 순서를 상세히 기록**하였습니다. 이 기록은 2세기 중엽 기독교 예배의 표준 구조를 보여줍니다.
- **히폴리투스의 『사도전승』(Apostolic Tradition, 3세기 초):** 성찬 제정사, 세례 예식, 서품식 등의 표준 예문이 체계화되었습니다.

### 3) 공인 이후 (4세기 이후: 콘스탄티누스 시대)
- 주후 313년 밀라노 칙령으로 기독교가 공인되면서 바실리카(Basilica) 양식의 대규모 공공 예배당이 건립되었습니다.
- 황실 의전과 결합하여 사제의 복장, 향, 촛대, 성가대 행진 등 시각적·의식적 요소가 장엄하게 확대되었습니다.
- 부활절 중심의 교회력에 성탄절, 사순절, 주현절 등이 체계적으로 정착되었습니다.

## 3. 2세기 초대교회 주일 예배의 표준 구조 (저스틴 마터의 기록 중심)

저스틴의 『제1변증서』(Apology I, 65-67장)에 묘사된 예배 순서는 현대 기독교 예배(말씀과 성찬)의 원형입니다.

| 구분 | 순서 | 주요 내용 |
| :--- | :--- | :--- |
| **말씀의 예전**<br>*(Liturgy of the Word)*<br>*(학습인과 불신자도 참여 가능)* | **1. 성경 낭독** | "시간이 허락하는 한" 사도들의 회고록(복음서)이나 예언자들의 글(구약)을 낭독함. |
| | **2. 강론 (설교)** | 낭독이 끝나면 인도자(감독)가 회중에게 들은 말씀을 본받아 살도록 권면하고 격려함. |
| | **3. 공동 기도** | 회중 전체가 자리에서 일어나 자신들과 세상의 구원, 통치자들을 위해 간절히 기도함. |
| | *(학습인 퇴장)* | 세례 준비자나 회개자들은 축복기도를 받은 후 퇴장함. |
| **성찬의 예전**<br>*(Liturgy of the Upper Room)*<br>*(세례받은 신자만 참여)* | **4. 평화의 입맞춤** | 기도를 마친 후 성도 간에 거룩한 입맞춤으로 화해와 일치를 고백함. |
| | **5. 봉헌** | 떡과 물을 탄 포도주를 인도자에게 가져옴. |
| | **6. 성찬 기도(Eucharistia)** | 인도자가 창조와 구원(예수 그리스도)에 대해 하나님께 긴 감사와 찬양의 기도를 드리고, 온 회중이 "아멘"으로 화답함. |
| | **7. 성찬 분병/분잔** | 감사의 기도를 거친 떡과 포도주를 집사들이 회중에게 나누어 주며, 자리에 참석하지 못한 병자들에게는 집사가 직접 전해줌. |
| | **8. 구제 헌금** | 여유가 있는 자들이 자발적으로 헌금을 바치며, 모인 헌금은 과부, 고아, 투옥된 자, 나그네를 구제하는 데 사용됨. |

## 4. 초대교회 예배의 주요 신학적·실천적 특징

1. **부활의 기쁨과 종말론적 대망**
   - 초대교회 예배의 핵심 기조는 엄숙한 슬픔이 아니라 **부활의 승리와 기쁨**이었습니다. 신자들은 주일에 무릎을 꿇지 않고 서서 기도했는데, 이는 그리스도와 함께 부활하여 자유롭게 된 자의 신분을 상징했습니다.
   - "마라나타(Maranatha, 주 예수여 오시옵소서)"를 외치며 다시 오실 그리스도를 기다리는 종말론적 기대감이 충만했습니다.

2. **철저한 공동체성과 평등성**
   - 로마 사회의 엄격한 계급 제도(귀족, 평민, 노예)가 교회 문턱 안에서는 무너졌습니다. 한 식탁에서 노예와 주인이 같은 떡과 잔을 나누며 형제자매로 교제했습니다.

3. **신비의 보호(Disciplina Arcani)와 세례의 엄격성**
   - 당시 박해 상황과 성찬의 신성함을 지키기 위해, 세례받지 않은 자(구도자/카테큐멘)는 전반부 말씀 예배까지만 참여할 수 있었고, 성찬식 전에는 예배당을 나가야 했습니다.
   - 세례는 통상 수년간의 교리 교육과 도덕적 검증을 거친 후 부활절 전야에 엄숙하게 베풀어졌습니다.

4. **예배와 디아코니아(나눔·섬김)의 일치**
   - 예배에서 드려진 물질(헌물)은 성직자의 부를 축적하는 데 쓰이지 않고, 고아와 과부, 빈민, 환자, 감옥에 갇힌 자들을 돕는 구제비로 즉각 사용되었습니다. 즉, 하나님을 향한 예배가 이웃을 향한 사랑의 실천과 직결되었습니다.

---

## 5. 현대적 의의

- **말씀과 성찬의 균형:** 현대 개신교 예배가 설교(말씀)에 치중하거나 일부 전통 교회가 의식에 치중하는 경향과 달리, 초대교회는 **말씀을 통한 계시와 성찬을 통한 연합**이 유기적으로 균형을 이루었습니다.
- **예배자 모두의 능동적 참여:** 성도들은 단순한 관람객이 아니라 기도의 "아멘" 복창, 평화의 입맞춤, 떡과 잔의 나눔을 통해 살아있는 제사장으로 참여했습니다.
- **삶으로 이어지는 예배:** 주일 모임에서 받은 은혜와 나눔은 평일의 세상 속에서 정결한 도덕적 삶과 이웃 사랑으로 확장되었습니다.
